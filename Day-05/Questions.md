### Important Memory Trick 🧠

```text
len()       → Length
[0]         → First character
[-1]        → Last character
[start:end] → Slice

.upper()    → UPPERCASE
.lower()    → lowercase
.strip()    → Remove extra spaces
.replace()  → Replace text
.find()     → Find position
```
