# 🐍 Day 02 — Variables & Data Types

## 1. What is a Variable?

A variable is a name used to store a value.

Basic syntax:

```python
variable_name = value
```

Example:

```python
name = "Rohit"
age = 20
salary = 30000
```

---

## 2. Printing Variables

Variables can be displayed using `print()`.

```python
name = "Rohit"

print(name)
```

Output:

```text
Rohit
```

---

## 3. Main Python Data Types

### int

`int` represents whole numbers.

```python
age = 20
salary = 30000
```

---

### float

`float` represents decimal numbers.

```python
rating = 4.5
percentage = 85.5
```

---

### str

`str` represents text.

```python
name = "Rohit"
city = "Vapi"
```

---

### bool

`bool` represents True or False.

```python
is_student = True
is_employee = False
```

---

## 4. type()

The `type()` function is used to check the data type of a value.

Example:

```python
age = 20

print(type(age))
```

Output:

```text
<class 'int'>
```

---

## 5. Variables in Calculations

Variables can be used in mathematical calculations.

Example:

```python
salary = 30000
bonus = 5000

total = salary + bonus

print(total)
```

Output:

```text
35000
```

---

## 6. Important Operators

| Operator | Meaning        |
| -------- | -------------- |
| `+`      | Addition       |
| `-`      | Subtraction    |
| `*`      | Multiplication |
| `/`      | Division       |

---

## 🧠 Easy Memory Trick

```text
int   → Whole Number
float → Decimal Number
str   → Text
bool  → True / False
```

---

## 📊 Data Analytics Connection

Variables are extremely important in Data Analytics.

For example:

```python
sales = 50000
expenses = 30000

profit = sales - expenses

print(profit)
```

The same basic idea will later be used with large datasets and Pandas.
