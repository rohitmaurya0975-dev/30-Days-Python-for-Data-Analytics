# 🐍 Day 12 — break, continue & pass

## 📚 Topics Covered

* `break` Statement
* `continue` Statement
* `pass` Statement
* Difference Between break, continue and pass
* Loop Control in Python
* Real-World Business Examples

---

## 📝 Practice Questions

### Q1. Break Statement

Write a Python program to print numbers from 1 to 10. Stop the loop when the number becomes 5 using `break`.

### Q2. Continue Statement

Print numbers from 1 to 10, but skip number 5 using `continue`.

### Q3. Pass Statement

Write a program that prints numbers from 1 to 5 and uses `pass` when the number is 3.

### Q4. Skip Even Numbers

Print numbers from 1 to 20, but skip all even numbers using `continue`.

### Q5. Stop at a Specific Number

Print numbers from 1 to 15. Stop the loop when the number becomes 8.

### Q6. Skip Zero Sales

Given the sales data:

```python
sales = [1000, 0, 2000, 0, 3000, 4000]
```

Use `continue` to skip zero-sales values and print the remaining values.

### Q7. Find the First Multiple

Print numbers from 1 to 50 and stop the loop when you find the first number divisible by 7.

### Q8. Skip Negative Numbers

Given the list:

```python
numbers = [10, -5, 20, -2, 30, -8, 40]
```

Use `continue` to print only positive numbers.

### Q9. Inventory Stock Check

Given the inventory:

```python
stock = [10, 8, 5, 2, 0, 7, 9]
```

Print the stock quantities. If stock becomes zero, display `"Out of Stock"` and stop the loop using `break`.

### Q10. Filter Sales

Given the sales data:

```python
sales = [500, 1500, 800, 2500, 1200, 700]
```

Use `continue` to skip sales values below 1000 and print the remaining sales.

### Q11. Search for a Number

Given the list:

```python
numbers = [12, 25, 37, 48, 59, 60]
```

Find the number 48. Stop searching once it is found using `break`.

### Q12. Password Attempts

Allow a user to enter a password up to 5 times. If the password is correct, display `"Login Successful"` and stop the loop using `break`.

### Q13. Multiplication Table

Print the multiplication table of 5 from 1 to 10, but skip the multiplication by 5 using `continue`.

### Q14. Difference Between Statements

Explain the difference between `break`, `continue`, and `pass` with one example of each.

### Q15. Business Problem — Sales Analysis ⭐

Given the sales data:

```python
sales = [1200, 0, 2500, 800, 3500, 0, 4200]
```

Write a program to:

1. Skip zero-sales values.
2. Skip sales below 1000.
3. Print the remaining sales values.
4. Calculate the total of the printed sales values.
