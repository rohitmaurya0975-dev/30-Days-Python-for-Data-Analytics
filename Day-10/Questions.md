# 🟢 PART 1 — Beginner Level

## Q01. Print Numbers
Use a for loop to print numbers from 1 to 10.

## Q02. Print Numbers in Reverse
Use a for loop to print numbers from 10 to 1.

## Q03. Even Numbers
Print all even numbers from 1 to 20 using a for loop.

## Q04. Odd Numbers
Print all odd numbers from 1 to 20 using a for loop.

## Q05. Multiplication Table
Take a number from the user and print its multiplication table
from 1 to 10.

Example:
Input: 5

Output:
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50

# 🟡 PART 2 — Intermediate Level

## Q06. Sum of Numbers
Calculate the sum of all numbers from 1 to 100 using a for loop.

## Q07. List Elements
Given the list:

    numbers = [10, 20, 30, 40, 50]

Print every element using a for loop.

## Q08. Sum of List Elements
Given the list:

    numbers = [10, 20, 30, 40, 50]

Calculate the total sum using a for loop.

Expected Output: 150

## Q09. Count Even Numbers
Given the list:

    numbers = [12, 7, 8, 15, 20, 31, 44, 9]

Count how many numbers are even.

## Q10. Factorial Using a Loop
Take a non-negative integer from the user and calculate its
factorial using a for loop.

Example:
Input: 5
Output: 120

Remember:
0! = 1

# 🔵 PART 3 — Data Analytics Practice

## Q11. Total Sales
Given the sales list:

    sales = [1000, 2500, 1800, 4000, 5000]

Calculate and print the total sales using a for loop.

## Q12. High Sales
Given the list:

    sales = [1000, 2500, 1800, 4000, 5000]

Print only sales values greater than or equal to 3000.

## Q13. Count High Sales
Given the list:

    sales = [1000, 3500, 1800, 4500, 5000, 1200]

Count how many sales values are greater than or equal to 3000.

## Q14. Inventory Value
Given the list of product prices:

    prices = [500, 1200, 800, 2000, 1500]

Calculate the total value of all five items, assuming one unit
of each product is available.

## Q15. Sales Performance
Given the list:

    sales = [12000, 25000, 8000, 45000, 18000]

Use a for loop and an if statement to classify each sale:

- Sales >= 30000: High Sales
- Sales >= 15000: Medium Sales
- Sales < 15000: Low Sales

Print each sale and its category.
