## 🟢 Beginner Practice

### Q01 — Create a Function

Create a function named `greet()` that prints:

```text
Hello Python
```

### Q02 — Welcome Message

Create a function named `welcome()` that prints:

```text
Welcome to Data Analytics!
```

Call the function three times.

### Q03 — Square of a Number

Create a function named `square(number)` that prints the square of a number.

Example:

```python
square(5)
```

Expected output:

```text
25
```

### Q04 — Display a Name

Create a function named `display_name(name)` that prints the given name.

Call it with three different names.

### Q05 — Add Two Numbers

Create a function named `add(a, b)` that prints the sum of two numbers.

Example:

```python
add(10, 20)
```

Expected output:

```text
30
```

### Q07 — Multiplication

### Q08 — Calculate Profit

Create a function named `calculate_profit(revenue, cost)` that returns the profit.

Formula:

```text
Profit = Revenue - Cost
```

Test it with:

```text
Revenue = 15000
Cost = 9000
```

### Q09 — Calculate Total Sales

Create a function named `calculate_sales(price, quantity)` that returns the total sales amount.

Formula:

```text
Total Sales = Price × Quantity
```

Test it with:

```text
Price = 500
Quantity = 4
```

### Q10 — Average of Three Numbers

Create a function named `calculate_average(a, b, c)` that returns the average of three numbers.

Formula:

```text
Average = (a + b + c) / 3
```
