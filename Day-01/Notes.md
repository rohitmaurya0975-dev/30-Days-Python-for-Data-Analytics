# 🐍 Day 01 — Python Basics Notes

## 1. What is Python?

Python is a programming language used to give instructions to a computer.

Python is widely used in Data Analytics, Data Science, Automation, Web Development, and Artificial Intelligence.

---

## 2. print()

The `print()` function is used to display information on the screen.

Example:

```python
print("Hello World")
```

Output:

```text
Hello World
```

---

## 3. Printing Text

Text is generally written inside quotation marks.

```python
print("Python")
```

---

## 4. Printing Numbers

Numbers can be printed without quotation marks.

```python
print(100)
```

---

## 5. Basic Calculations

Python can perform mathematical operations.

```python
print(10 + 5)
print(10 - 5)
print(10 * 5)
print(10 / 5)
```

Operators:

| Operator | Meaning        |
| -------- | -------------- |
| `+`      | Addition       |
| `-`      | Subtraction    |
| `*`      | Multiplication |
| `/`      | Division       |

---

## 6. Comments

Comments are notes written inside the code.

Python ignores comments while executing the program.

A comment starts with `#`.

```python
# This is a comment
print("Hello")
```
