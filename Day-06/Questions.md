# 🐍 Day 06 — Python Lists

## 30 Days Python Challenge for Data Analytics

**Topics:** List Creation, Indexing, Negative Indexing, `len()`, `append()`, `insert()`, `remove()`, `pop()`, `sort()`

### Q01. Create a List

Create a list named `fruits` containing `"Apple"`, `"Mango"`, and `"Banana"`. Print the complete list.

### Q02. Access List Items

Given:

```python
students = ["Rahul", "Priya", "Amit", "Neha"]
```

Print the first student and the third student using indexing.

### Q03. Negative Indexing

Using the same `students` list, print the last student and the second-last student.

### Q04. Count Items

Given:

```python
marks = [85, 90, 78, 92, 88]
```

Use `len()` to print the total number of marks.

### Q05. Update a List Item

Given:

```python
marks = [70, 80, 60, 90]
```

Change the third item to `75` and print the updated list.

### Q06. Add an Item Using append()

Given:

```python
employees = ["Rahul", "Priya", "Amit"]
```

Add `"Neha"` to the end of the list using `append()` and print the list.

### Q07. Insert an Item

Given:

```python
students = ["Rahul", "Amit", "Neha"]
```

Insert `"Priya"` at index `1` using `insert()` and print the updated list.

### Q08. Remove an Item

Given:

```python
employees = ["Rahul", "Priya", "Amit", "Neha"]
```

Remove `"Amit"` using `remove()` and print the updated list.

### Q09. Use pop()

Given:

```python
numbers = [10, 20, 30, 40]
```

Remove the item at index `1` using `pop()` and print the updated list.

### Q10. Sort Sales Data

Given:

```python
daily_sales = [5000, 7500, 6200, 9000, 8500]
```

1. Print the sales in ascending order.
2. Print the sales in descending order.

A shop recorded the following daily sales:

Perform the following tasks:
